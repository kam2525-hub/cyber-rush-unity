# CYBER RUSH // サイバー剣戟×銃撃アクション

ハイスピード一人称サイバーパンク・カタナ＆ガンアクションゲーム（Unity 6.2 Built-in RP + Blender 4.5 ハードサーフェス3Dアセット）。

---

## 主な特徴 (Features)

1. **全5ステージ＋ボスラッシュ（ソロアクション特化）**
   - **Stage 1: ネオンスカイライン** — 高層ビル群を駆け抜ける基本パルクール＆コンボ
   - **Stage 2: サイバーキャニオン** — 連続ウォールラン＋ダブルグラップル
   - **Stage 3: アルコン尖塔** — シールドパイロン破壊＋巨大コアボス戦
   - **Stage 4: キルチェイン回廊** — 多数の敵を連続撃破してスローモ＆ダッシュリセットを繋ぐ高速回廊
   - **Stage 5: スカイフォートレス** — 空中要塞の護衛部隊＆最終コアボス決戦
   - **BOSS RUSH**: アルコンコア直接対決（100 HP制）

2. **スタイリッシュ撃破スローモーション＆豪華撃破SE**
   - 敵を撃破するたびに短いヒットストップ＋滑らかなスローモーション演出（`CyberVFX.TriggerStylishKillSlowMo`）＋ネオンシャッター爆散・衝撃波リングを発動。
   - **豪華撃破SE (`kill_deluxe` / `boss_kill`)**: サブベース衝撃ドロップ＋クリスタル和音チャイム＋電撃アーマー破砕音をリアルタイム合成（`CyberAudio.cs`）。

3. **剣技＆サイバー銃アクション (`[1]` カタナ / `[2]` 銃)**
   - **カタナ**: `[LMB]` 3段コンボ斬撃＆敵弾ジャスト反射、`[Q]` 貫通斬撃波、`[F]` 360°旋風斬、`空中+[C]` 急降下斬撃
   - **サイバー銃**: `[LMB]` 重厚パルス銃撃、`[Q]` 貫通レールガン、`[F]` 5発拡散ショット（カタナ装備中も `[G]` でクイック射撃可能）

## 操作方法 (Controls)

| 入力 | アクション |
| --- | --- |
| `W / A / S / D` | 移動 |
| `Mouse` | 視点操作（`Alt` でカーソル切替、`ESC` でメインメニュー） |
| `Space` | ジャンプ / ウォールジャンプ |
| `Left Shift` / `RMB` | ダッシュ / 長押しでスローモーション |
| `C` (地上 / 空中) | スライディング / 急降下斬撃 |
| `E` | グラップルアンカーへワイヤー移動 |
| `1` / `2` / `Wheel` | カタナ ⇔ サイバー銃 切替 |
| `LMB` | 通常攻撃（斬撃＋弾反射 / パルス銃撃） |
| `Q` | スキル1（斬撃波 / 貫通レールガン） |
| `F` | スキル2（旋風斬 / 拡散ショット） |
| `G` | クイック銃撃（いつでも発砲可能） |
| `R` / `M` | リトライ / サウンドON・OFF |
